About Vectorizer-svg

A lightweight linear algebra library (especially for vectors), focused on graphing and derivatives.

Install the library

To install the vectorizer-svg library, run the following command in your terminal:

pip install vectorizer-svg

Modules in the library :

  • Vector : Used to create vectors
  • gradient : Used to create gradient vector
  • vector_derivative : Used to derivativing vectors
  • plot_vectors : Used to plotting vectors
