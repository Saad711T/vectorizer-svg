# Vectorizer-svg

Simple Linear Algebra Library with SVG Manipulation

## Installation

```bash
pip install vectorizer-svg
```

[PyPi](https://pypi.org/project/vectorizer-svg/0.1.1/)

## Features

- Vectors graph
- Operations on vectors
- Gradient vector
- Dot and Cross products
